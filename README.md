# Karibandi Suresh — Data Analyst Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example, `suresh-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your public website URL in the Pages section.
